# Parameter tuning

This folder contains notebooks and helpers for tuning ALNS-related parameters.

## Results & Models

Parameter tuning outputs follow the same convention and are written to:

```
hybrid_ml_metaheuristics/hybrid_alns/results/<dataset_key>/<YYYYMMDD_HHMMSS>/
	results.csv
	graphs/
```

Trained models (`.pkl`) are stored in `.../models/` and are not gitignored.
