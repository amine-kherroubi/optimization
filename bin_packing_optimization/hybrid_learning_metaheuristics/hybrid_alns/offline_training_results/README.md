# Offline Training Results

This folder stores exported artifacts from offline training runs for the hybrid ALNS repair model. Results are grouped by execution platform for convenience.

## Available runs

- Kaggle: approximately 4 hours
- Google Colab: approximately 5 hours 17 minutes

## Organization

- `collab_results/`: results from the Colab-based workflow
- `kaggle_results/`: results from the Kaggle-based workflow
