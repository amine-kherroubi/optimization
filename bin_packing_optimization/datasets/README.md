# Benchmarking Datasets

The repository ships with a curated collection of benchmark instances for the 1D Bin Packing Problem. Instances are stored as plain-text files using a simple, dataset-agnostic format.

## File format

Each instance file contains:

1. The number of items $n$
2. The bin capacity $c$
3. One item weight per line for the $n$ items

## Available benchmark families

### Falkenauer
Instances introduced by E. Falkenauer in [A hybrid grouping genetic algorithm for bin packing](https://link.springer.com/article/10.1007/BF00226291). They are divided into two groups: Falkenauer U (uniform item sizes) and Falkenauer T (triplet-based instances).

### Scholl
Instances introduced by A. Scholl, R. Klein, and C. Jürgens in [BISON: a fast hybrid procedure for exactly solving the one-dimensional bin packing problem](https://www.sciencedirect.com/science/article/pii/S0305054896000822). These include multiple parameterized sets with varying capacities and instance sizes.

### Wäscher
A set of hard instances used by G. Wäscher and T. Gau in [Heuristics for the integer one-dimensional cutting stock problem: a computational study](https://link.springer.com/article/10.1007/BF01539705).

### Schwerin
Instances introduced by P. Schwerin and G. Wäscher in [The bin-packing problem: a problem generator and some numerical experiments with FFD packing and MTP](https://www.sciencedirect.com/science/article/pii/S0969601697000257).

### Hard28
A compact set of difficult instances reported by J. E. Schoenfield in a technical report on exact bin packing methods.

### Randomly generated
Instances generated by M. Delorme, M. Iori, and S. Martello in [Bin Packing and Cutting Stock Problems: Mathematical Models and Exact Algorithms](https://www.sciencedirect.com/science/article/pii/S0377221716302491). These instances vary across item count, capacity, and weight range.

### ANI AI, GI, and SSTriples
Additional benchmark families collected from the literature and packaged alongside the repository for reproducible comparison.
